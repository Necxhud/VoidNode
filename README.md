# VoidNode

> Твой узел свободы.

VoidNode — защищённый мессенджер для свободного и анонимного общения.
Твой узел свободы в скрытой сети.

## Статус

🚧 Ранняя разработка.

Сейчас проект содержит первый Android-экран VoidNode.
Следующая цель — локальные профили, чаты и хранение сообщений на устройстве.

## Стек

- Android UI: Kotlin + Jetpack Compose
- Ядро: C++
- Сборка APK: GitHub Actions
- Будущая база: SQLite
- Дополнения: NodeStore

## Принципы

- Приватность по умолчанию
- Свобода общения
- Локальный контроль над данными
- Модульность
- Минимум централизованных сервисов
